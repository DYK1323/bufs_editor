# 8.6 기본 표 설정

표 자동화와 마크다운 표 변환 뒤에 적용할 기본 서식을 정합니다. 이미 만들어진 표에서는 `표 자동화` 버튼이 이 설정을 사용하고, 마크다운 표를 한글 표로 바꿀 때도 같은 설정이 적용됩니다.

![표 설정 화면](../assets/screenshots/표설정.png)

주로 확인할 항목은 다음과 같습니다.

- 기본 문단 스타일
- 기본 표 스타일
- 기본 셀 안 여백
- 기본 표 바깥 여백
- 너비맞추기 결과

표를 자주 만들거나 외부에서 가져온 표를 같은 모양으로 정리해야 한다면 이 설정을 먼저 맞춰 두는 편이 좋습니다.

마크다운 표 변환 중 한글의 붙여넣기 선택 창이 뜨면 `원본 형식 유지`를 선택해야 합니다. 이 옵션을 골라야 앱이 클립보드에 넣은 HTML 표 형식을 한글 표로 가져올 수 있습니다.
