# 4.4 `쪽 편집` 탭

`쪽 편집` 탭에서는 머리말, 꼬리말, 쪽번호를 감추거나 새 번호 개체를 넣습니다.

![쪽 편집 탭 화면](../assets/screenshots/쪽편집.png)

주요 기능은 다음과 같습니다.

| 영역 또는 버튼 | 언제 사용하나요 |
| --- | --- |
| `모두 감추기(머리말/꼬리말/쪽번호)` | 현재 구역에서 머리말, 꼬리말, 쪽번호를 한 번에 감춥니다. 표지나 간지처럼 번호가 보이면 안 되는 쪽에서 사용합니다. |
| `새 쪽 번호` | 현재 위치에 새 쪽 번호 개체를 넣습니다. |
| `새 표 번호` | 현재 위치에 새 표 번호 개체를 넣습니다. 표 캡션을 직접 만들 때 사용합니다. |
| `새 그림 번호` | 현재 위치에 새 그림 번호 개체를 넣습니다. 그림 캡션을 직접 만들 때 사용합니다. |
| `머리말 양쪽` | 양쪽 페이지에 적용되는 머리말 영역을 만듭니다. |
| `머리말 짝수쪽` | 짝수쪽 전용 머리말 영역을 만듭니다. 좌우 페이지 머리말을 다르게 둘 때 사용합니다. |
| `머리말 홀수쪽` | 홀수쪽 전용 머리말 영역을 만듭니다. 좌우 페이지 머리말을 다르게 둘 때 사용합니다. |

새 번호 개체는 표 번호나 그림 번호처럼 한글의 자동 번호를 넣을 때 씁니다. 번호를 넣을 위치에 커서를 둔 뒤 실행합니다.
