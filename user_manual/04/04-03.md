# 4.3 `표 편집` 탭

`표 편집` 탭에서는 표의 색상, 선, 여백, 제목셀, 캡션을 정리합니다.

![표 편집 탭 화면](../assets/screenshots/표편집.png)

주요 기능은 다음과 같습니다.

| 영역 또는 버튼 | 언제 사용하나요 |
| --- | --- |
| 셀 배경색 | 선택한 셀에 배경색을 적용합니다. 제목셀, 합계행, 강조 셀을 구분할 때 사용합니다. |
| 글자색 | 선택한 셀이나 표 안 글자에 글자색을 적용합니다. |
| 표내용 스타일 | 표 안 문단에 `표내용-왼쪽`, `표내용-중간`, `표내용-오른쪽` 같은 표 전용 문단 스타일을 적용합니다. |
| `글자스타일제거` | 표 안에 직접 들어간 글자 스타일만 지웁니다. 문단 스타일은 유지합니다. |
| 표 스타일 | 표 전체 선, 제목행, 기본 문단 스타일을 한 번에 맞춥니다. |
| 테두리 | 선택한 셀이나 표에 선 프리셋을 적용합니다. 전체선, 위/아래선, 안쪽선처럼 반복되는 표 선 정리에 사용합니다. |
| 제목셀 자동화 | 표 첫 행이나 선택한 셀을 제목셀처럼 정리합니다. 배경색, 글자색, 정렬, 스타일을 함께 맞출 때 사용합니다. |
| `셀여백` | 선택한 셀 안쪽 여백을 표준값으로 맞춥니다. 표 안 글자가 셀 경계에 너무 붙어 보일 때 사용합니다. |
| `표여백` | 표 바깥 여백과 배치를 정리합니다. 본문 흐름 안에서 표가 자연스럽게 보이도록 맞춥니다. |
| `너비맞추기` | 선택한 표나 셀의 너비를 문서 폭 또는 현재 셀 기준에 맞추려고 합니다. |
| `캡션원클릭` | 표 위 문장을 표 캡션으로 바꾸고 필요한 경우 표 번호 개체를 함께 넣습니다. |
| 번호종류 | 선택한 표가 자동 번호에 들어갈 대상인지 정합니다. |
| 마크다운 표를 한글 표로 변환 | ChatGPT나 Markdown 문서에서 가져온 pipe table을 한글 표로 바꿉니다. |
| `표 설정` | 색상, 선 프리셋, 제목셀, 캡션 인식 규칙 같은 표 관련 설정을 엽니다. |

표 기능은 선택 상태에 따라 결과가 달라집니다. 셀 일부를 선택하면 선택한 셀에 적용됩니다. 표 안에 커서만 두면 현재 표를 기준으로 적용하려고 시도합니다.

`번호종류`는 한글의 자동 캡션 번호가 꼬이지 않게 관리할 때 중요합니다. 본문에서 번호를 매겨야 하는 실제 표는 `표`로 두고, 그림 캡션을 붙일 대상은 `그림`으로 둡니다. 표 안의 작은 보조 표, 배치용 표, 증빙 양식 안쪽 표처럼 캡션 번호에 들어가면 안 되는 표는 `없음`으로 바꿉니다. 이렇게 해 두면 뒤쪽의 `표 1`, `표 2` 번호가 불필요한 보조 표 때문에 밀리는 일을 줄일 수 있습니다.
