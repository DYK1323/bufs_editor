# BUFS 한글 편집기 사용설명서 상세 목차 초안

문서 목적: 한글 파일로 보고서를 작성하는 행정직원이 BUFS 한글 편집기를 안전하게 사용하고, 부서 또는 문서 유형에 맞게 스타일과 표 설정을 직접 조정할 수 있도록 안내한다.

기본 독자:

- 한글에서 보고서, 공문, 표가 포함된 문서를 작성한다.
- 한글의 문단 스타일, 글자 스타일, 번호 스타일 개념은 잘 모를 수 있다.
- JSON 설정 파일을 직접 편집하기보다 앱 화면의 `관리`, `표 설정` 창에서 설정하는 방식을 선호한다.
- 반복되는 보고서 편집 작업을 줄이고 싶지만, 문서 전체가 의도치 않게 바뀌는 것은 원하지 않는다.

권장 산출물:

- `user_manual/user_manual.md`: 전체 사용설명서 원본
- `user_manual/quick_start.md`: 1장짜리 빠른 사용법
- `user_manual/terms.md`: 용어 설명
- 배포 시 PDF 변환본: `BUFS-HWP-Editor-사용설명서.pdf`

## 1. 빠른 시작

### 1.1 이 앱으로 할 수 있는 일

- 보고서 본문 스타일 정리
- 표 배경색, 글자색, 선, 제목셀 정리
- 숫자, 날짜, 단위, 수동 줄바꿈 정리
- 표지 또는 보고양식 불러오기
- BUFS 로고 삽입
- 마크다운 표를 한글 표로 변환
- 캡션 문장을 표/그림 캡션으로 바꾸기

### 1.2 사용 전 준비

- Windows PC
- 한컴오피스 한글 설치
- 편집할 한글 문서를 먼저 열어두기
- 가능하면 `.hwpx` 형식 문서 사용
- 배포받은 `BUFS-HWP-Editor.exe` 실행

### 1.3 가장 기본적인 사용 흐름

1. 한글에서 문서를 연다.
2. 앱을 실행한다.
3. `상태` 탭에서 대상 문서를 확인한다.
4. 한글 문서에서 바꿀 문단, 텍스트, 표, 셀을 선택한다.
5. 앱에서 필요한 버튼을 누른다.
6. 결과가 마음에 들지 않으면 한글의 실행취소 또는 앱의 실행취소를 사용한다.

### 1.4 처음 사용할 때 꼭 알아야 할 원칙

- 앱은 현재 열려 있는 한글 문서에 적용된다.
- 대부분의 기능은 한글에서 선택한 부분에만 적용된다.
- 표 기능은 표 안에 커서를 두거나 셀/표를 선택해야 한다.
- 스타일 적용은 현재 한글 문서에 같은 이름의 스타일이 있어야 안정적으로 동작한다.
- 중요한 문서는 작업 전 저장하거나 복사본으로 테스트한다.

## 4. 보고서 작성 흐름별 사용법

### 4.1 새 보고서 시작하기

- 빈 문서에서 보고양식 불러오기
- 기존 문서에 표지 추가하기
- 제목, 날짜, 부서명 입력 형식

### 4.2 본문 초안 일괄처리하기

- `스타일/정리` 탭의 `관리`에서 식별자 확인
- 문단 스타일별 식별자 입력
- 표 안 스타일이면 `표` 체크
- 자동 굵게용 스타일은 `글자`로 등록
- 글자 스타일 역할 확인
- `규칙` 탭의 글자 역할 확인
- 직접 쓴 초안 또는 가져온 본문 전체 선택
- `일괄처리` 실행
- 식별자 또는 개요 표시자에 따른 스타일 적용 결과 확인
- 자동 굵게 적용 결과 확인

### 4.3 숫자와 날짜 정리하기

- 천원단위 쉼표 넣기
- 쉼표 빼기
- 소숫점 처리
- 단위 변환
- 날짜 형식 통일
- 요일 추가와 제거

### 4.4 표 정리하기

- 표 안에 커서 두기
- 표 전체 또는 일부 셀 선택
- 표내용 스타일 적용
- 표내용 스타일 버튼은 `표` 체크된 문단 스타일에서 만들어짐
- 표 스타일 아이콘으로 표 전체 선과 제목셀 함께 적용
- 표 선 프리셋 적용
- 제목셀 자동화
- 셀여백과 표여백
- 너비맞추기

### 4.5 캡션 만들기

- `[표 5.4-8] 제목` 형식의 문장 준비
- 문장 선택
- 바로 아래 표 또는 근처 표를 대상으로 `캡션원클릭`
- 캡션 스타일 적용 확인
- 표/그림 번호 종류 확인
- 번호에서 제외할 보조 표는 `번호종류`에서 `없음` 처리

### 4.6 마크다운 표를 한글 표로 바꾸기

- 마크다운 표 텍스트 선택
- `markdown 표 → 한글 표`
- 붙여넣기 선택 창에서 `원본 형식 유지` 선택
- 변환 뒤 기본 표 스타일, 셀여백, 표여백, 너비맞추기 확인
- GIF 후보: 선택한 마크다운 표가 한글 표로 바뀌는 과정

### 4.7 최종 점검

- 대상 문서 확인
- 실행취소 가능 여부
- 저장 전 표/캡션/번호 확인
- PDF 저장 전 점검

## 5. 스타일 설정 이해하기

### 5.1 스타일 세트란 무엇인가

- 문서 유형별 스타일 묶음
- 예: 보고서용, 일반보고용, 공문용
- 세트별로 문단 스타일, 글자 스타일, 자동 굵게 규칙을 다르게 관리

### 5.2 문단 스타일과 글자 스타일

- 문단 스타일: 한 문단 전체의 모양
- 글자 스타일: 선택한 글자 일부의 모양
- 일괄처리에서 두 스타일이 함께 쓰이는 방식

### 5.3 스타일 이름이 중요한 이유

- 앱은 현재 한글 문서의 같은 이름 스타일을 찾아 적용한다.
- 스타일 이름이 다르면 적용되지 않거나 다른 결과가 나올 수 있다.
- 한글의 스타일 불러오기에서 템플릿 양식을 선택해 실제 작업 문서로 스타일을 가져오는 것이 중요하다.

### 5.4 스타일 목록 순서 바꾸기

- `위로`
- `아래로`
- `기본순서`
- 순서 변경이 실제 문서 스타일에 미치는 영향

### 5.5 스타일 세트 관리 화면

- 세트 추가
- 세트 이름 변경
- 세트 복사
- 스타일 추가
- 스타일 수정
- 스타일 삭제
- 저장과 취소

## 6. 스타일 커스터마이징 항목 자세히 보기

### 6.1 `표` 체크박스

- 이 스타일이 표 안에서 쓰이는 스타일임을 표시
- 표 안 일괄처리, 표내용 스타일 버튼, 표용 굵게 규칙과 연결
- `표 편집` 탭에 보이는 표내용 스타일 버튼의 기준
- 예: `표내용-중간`, `표내용-왼쪽`, `표내용-굵게`

### 6.2 `캡션` 체크박스

- 이 스타일이 표/그림 캡션용임을 표시
- `캡션원클릭` 뒤 자동으로 적용할 캡션 스타일을 찾을 때 사용
- 예: `[표/그림] 캡션`

### 6.3 `식별자` 또는 `개요 표시자`

- 붙여넣은 문장 맨 앞의 기호나 약속어
- 예: `ㅇ`, `○`, `-`, `∙`, `표점`, `표삼각`
- 일괄처리가 표시자를 보고 어떤 문단 스타일을 적용할지 판단

### 6.4 `역할`

- 자동 굵게가 사용할 글자 스타일의 이름표
- `body_bold`: 본문에서 쓰는 굵게 글자 스타일
- `table_bold`: 표 안에서 쓰는 굵게 글자 스타일
- 역할은 글자 스타일에만 지정
- `규칙` 탭의 글자 역할과 같은 이름이어야 함
- 역할이 비어 있으면 자동 굵게가 해당 글자 스타일을 찾지 못할 수 있음

### 6.5 `그룹`

- 번호가 서로 섞이지 않도록 나누는 묶음
- `body`: 본문 번호용
- `table`: 표 안 번호용
- 같은 그룹 안에서만 상위/하위 번호 관계를 판단

### 6.6 `단계`

- 번호 또는 개요의 깊이
- 예: 1단계는 큰 항목, 2단계는 하위 항목, 3단계는 더 하위 항목
- 단계가 맞아야 새 번호 시작 규칙이 자연스럽게 동작

### 6.7 `상위 개요 뒤 새 번호`

- 상위 단계가 새로 나오면 하위 번호를 다시 시작하게 하는 설정
- 예: `1. 추진 배경` 뒤 하위 항목이 1, 2로 진행되고, `2. 추진 계획` 아래에서는 하위 항목을 다시 1부터 시작하고 싶을 때 사용
- 번호가 예상대로 다시 시작되지 않으면 그룹과 단계를 함께 확인

## 7. 일괄처리 규칙 이해하기

### 7.1 일괄처리가 하는 일

- 일괄처리 전 `관리`에서 식별자를 넣어야 함
- 문단 앞 표시자를 보고 문단 스타일 적용
- 첫머리 괄호 키워드 굵게
- 콜론 앞 키워드 굵게
- 마크다운 굵게 표시 제거 및 글자 스타일 적용
- 본문과 표 안 텍스트를 구분하여 처리

### 7.2 첫머리 괄호 키워드

- 예: `ㅇ (배경) 내용`
- 적용 결과: `(배경)` 부분에 굵게 스타일
- 괄호까지 포함할지 여부

### 7.3 첫머리 콜론 앞

- 예: `목적: 내용`
- 적용 결과: `목적` 부분에 굵게 스타일
- 콜론 자체를 포함할지 여부

### 7.4 마크다운 굵게

- 예: `**중요 내용**`
- 적용 결과: `**`는 제거하고 `중요 내용`에 굵게 스타일
- 본문과 표에서 서로 다른 굵게 스타일을 쓸 수 있음

### 7.5 본문과 표 구분

- 본문에서는 본문용 문단/글자 스타일 적용
- 표 안에서는 표용 문단/글자 스타일 적용
- 표 체크가 잘못되어 있으면 원하는 스타일이 적용되지 않을 수 있음

### 7.6 줄바꿈정리

- PDF나 웹에서 복사해 줄마다 끊긴 문장 정리
- 불필요한 수동 줄바꿈과 중복 띄어쓰기 정리
- 빈 줄, 목록처럼 보이는 줄, 콜론 뒤 줄은 가능한 한 유지
- 결과가 어색하면 실행취소

### 7.7 괄호 씌우기

- 선택한 규정명이나 문서명을 `｢ ｣`로 감싸기
- 이미 `「 」`로 감싸진 글자는 표준 모양으로 변환
- 한 줄 안의 필요한 글자만 선택
- 여러 줄 또는 표 셀 여러 칸 선택 시 중단

### 7.8 기호제거

- 문단 앞에 직접 입력한 개요 기호 제거
- 예: `ㅇ`, `○`, `-`, `ㆍ`, `※`
- 한글 문단 번호 모양도 함께 정리 시도
- 지울 기호가 없으면 안내

### 7.9 새 번호

- `스타일/정리` 탭의 수동 버튼
- 현재 커서가 있는 문단의 번호를 새 번호로 시작
- 하위 번호가 이어질 때 해당 하위 문단에 커서를 두고 사용
- 여러 곳에서 반복되면 `상위 개요 뒤 새 번호` 설정 확인
- 번호가 없는 일반 문단에서는 실패할 수 있음

## 8. 표 편집 설정 이해하기

### 8.1 색상 팔레트

- 색 이름
- RGB 값
- 용도
- 셀 배경색과 글자색 버튼에 나타나는 방식

### 8.2 선 프리셋

- 얇은 선
- 굵은 선
- 이중 선
- 점선
- 선 없음
- 선 굵기, 선 종류, 선 색상

### 8.3 제목셀 설정

- 배경색
- 글자색
- 문단 스타일
- 글자 스타일
- 위, 아래, 왼쪽, 오른쪽, 안쪽 가로, 안쪽 세로 테두리
- 각 선 색상

### 8.4 셀 안 여백

- 왼쪽, 오른쪽, 위, 아래
- 표 안 글자가 셀 경계와 너무 붙어 보일 때 조정

### 8.5 표 바깥 여백

- 왼쪽, 오른쪽, 위, 아래
- 표와 본문 사이 간격 조정

### 8.6 기본 표 설정

- 표 자동화와 마크다운 표 변환 공통 기본값
- 기본 문단 스타일
- 기본 표 스타일
- 기본 셀여백, 표여백, 너비맞추기 적용 흐름

### 8.7 표 스타일 버튼

- 표 전체 선 적용
- 첫 줄 선택
- 제목셀 스타일 적용
- 실패할 때 확인할 것

### 8.8 엑셀표 정리

- 엑셀에서 붙여넣은 표 기본 모양 정리
- 흰색 배경, 검정 글자색, 얇은 전체 테두리
- `표내용-중간` 문단 스타일 적용 시도
- 제목셀은 표 스타일 버튼이나 제목셀 자동화로 추가 정리

## 9. 캡션 설정 이해하기

### 9.1 캡션원클릭이 하는 일

- 선택한 캡션 후보 문장을 읽는다.
- 표 또는 그림 종류를 파악한다.
- 번호 앞부분과 제목 뒷부분을 분리한다.
- 근처 표를 찾아 캡션을 만든다.
- 캡션 스타일을 적용한다.

### 9.2 기본 인식 예시

- `[표 5.4-8] 샘플표제통`
- `[그림 2.4-1] 학사관리 체계 개선 실적`

### 9.3 캡션 후보 문장 규칙

- 대괄호로 시작해야 함
- 대괄호 안 첫 낱말은 `표` 또는 `그림`
- 번호 앞부분에는 하이픈 `-` 필요
- 대괄호 뒤에 제목 입력
- 인식되는 예: `[표 1-1] 제목`, `[표 5.4-8] 제목`, `[그림 2.4-1] 제목`
- 기본 설정에서 인식하기 어려운 예: `표 1-1 제목`, `[표 1] 제목`, `[표 1.1] 제목`, `[사진 1-1] 제목`

### 9.4 캡션 인식 규칙

- 패턴
- 앞부분 템플릿
- 뒷부분 템플릿
- 샘플
- 인식 테스트

### 9.5 캡션 스타일과 번호 종류

- 캡션 체크된 스타일이 필요함
- 표 번호와 그림 번호 구분
- 번호 종류가 맞지 않을 때 확인할 것
- 번호를 붙이지 않을 표는 `번호종류`를 `없음`으로 변경

### 9.6 표 번호에서 제외할 표

- 표 안의 보조 표나 배치용 표가 번호를 밀 수 있음
- 제외할 표 선택
- `표 편집` 탭의 `번호종류`에서 `없음`
- 뒤쪽 캡션 번호 확인

## 13. 커스터마이징 예시

### 13.1 스타일 모양을 바꾸고 싶다

- 앱은 스타일 이름으로 한글 문서의 스타일을 찾음
- 이름은 그대로 두고 한글 문서에서 스타일 모양 편집
- 스타일을 새로 만들거나 불러온 뒤 적용되지 않으면 `상태` 탭에서 다시 연결
- 한글 2024 도움말 링크 안내

### 13.2 목록에 없던 새 스타일을 추가하고 싶다

- 한글 문서에 같은 이름의 스타일 추가
- 앱의 스타일 세트 관리에도 같은 이름으로 추가
- 문단 스타일과 글자 스타일 구분
- 자동 적용이 필요하면 식별자 또는 개요 표시자 입력
- 표용 스타일은 `표` 체크, 캡션 스타일은 `캡션` 체크
- 저장 후 테스트하고 필요하면 `상태` 탭에서 다시 연결

### 13.3 공통 양식 자체를 바꾸고 싶다

- 설치 폴더의 `bufs/templates`에 있는 양식 파일 관리
- 개인 문서에서는 양식을 직접 열지 않고 `스타일 불러오기`에서 선택
- 현재 문서에 양식을 넣을 때는 `양식/그림` 탭의 `보고양식 불러오기` 사용
- 양식 파일 수정 주의 사항은 부록의 템플릿 관리 참조

### 13.4 본문 식별자를 `ㅇ`에서 `○`로 바꾸고 싶다

- 스타일 세트 관리에서 해당 스타일의 식별자 또는 개요 표시자에 `○` 추가
- 일괄처리 테스트
- 실제 번호 모양이나 문단 모양을 바꾸려면 한글 문서의 스타일 편집

### 13.5 표 안 식별자를 `표점`에서 `-`로 바꾸고 싶다

- 표용 스타일에 `표` 체크
- 식별자 또는 개요 표시자에 `-` 추가
- 그룹은 `table`, 단계는 적절히 설정
- 표 안 문단 모양을 바꾸려면 한글 문서의 같은 이름 스타일 편집

### 13.6 제목셀 색을 바꾸고 싶다

- `표 설정`
- 색상 팔레트 확인 또는 색 추가
- 제목셀 배경색 변경
- 저장 후 `제목셀 자동화` 테스트

### 13.7 캡션 스타일 이름이 다르다

- 스타일 세트 관리
- 실제 한글 문서의 캡션 스타일 이름 추가
- `캡션` 체크
- 캡션원클릭 테스트

### 13.8 자동 굵게가 적용되지 않는다

- 글자 스타일이 있는지 확인
- 역할에 `body_bold` 또는 `table_bold`가 지정되어 있는지 확인
- 일괄처리 규칙이 켜져 있는지 확인

### 13.9 하위 번호가 다시 1번부터 시작되지 않는다

- 상위 항목과 하위 항목 예시 제시
- 같은 그룹인지 확인
- 상위/하위 단계가 맞는지 확인
- 다시 시작되어야 하는 하위 스타일에 `상위 개요 뒤 새 번호` 체크
- 본문 번호와 표 안 번호는 그룹을 나누어 관리
- 한두 곳만 고칠 때는 해당 문단에서 `새 번호` 버튼 사용
- 번호를 이어야 할 때는 `이어서` 버튼 사용

### 13.10 마크다운 표 변환 뒤 모양을 바꾸고 싶다

- Markdown 표 기본 문단 스타일 변경
- Markdown 표 스타일 변경
- 셀여백과 표여백 조정

## 14. 문제 해결

### 14.1 앱이 한글을 찾지 못함

- 한글 문서를 먼저 열었는지 확인
- `상태` 탭에서 다시 연결
- 한글 보안 모듈 관련 안내

### 14.2 대상 문서가 다른 것 같음

- `상태` 탭에서 대상 확인
- 여러 한글 창이 열려 있을 때 주의

### 14.3 버튼을 눌러도 변화가 없음

- 한글에서 선택 영역이 있는지 확인
- 커서가 표 안에 있는지 확인
- 현재 문서에 같은 이름의 스타일이 있는지 확인

### 14.4 스타일 적용이 이상함

- 문서 확장자가 `.hwp`이면 `.hwpx`로 저장 후 다시 연결
- 스타일 이름 확인
- 스타일 세트 확인
- 실제 한글 문서에 들어 있는 스타일 확인

### 14.5 표 기능이 실패함

- 표 개체가 선택되었는지 확인
- 셀 선택 상태인지 확인
- 복잡한 병합 셀이 있는지 확인

### 14.6 캡션원클릭이 실패함

- 캡션 후보 문장 형식 확인
- 바로 아래 또는 근처에 표가 있는지 확인
- 캡션 인식 테스트
- 캡션 체크된 스타일 확인

### 14.7 표 번호가 밀림

- 번호를 붙이면 안 되는 보조 표 확인
- 해당 표 선택
- `번호종류`를 `없음`으로 변경
- 뒤쪽 표 번호 재확인

### 14.8 자동 굵게가 안 됨

- 역할 확인
- 글자 스타일 확인
- 굵게용 스타일 종류가 `글자`인지 확인
- `규칙` 탭의 글자 역할 확인
- 본문/표 대상 구분 확인

### 14.9 번호가 이상하게 이어짐

- 그룹 확인
- 단계 확인
- 새 번호 시작 설정 확인
- 특정 문단 하나만 고칠 때는 `새 번호` 버튼 사용
- 번호를 이어야 할 때는 `이어서` 버튼 사용

### 14.10 숫자 정리나 단위 변환이 중단됨

- 콤마 위치가 이상한 숫자 확인
- 변환 대상 단위가 아닌 값 확인
- 표 셀 여러 칸 숫자 블록은 한 셀씩 실행

### 14.11 양식이나 증빙자료 삽입이 실패함

- 커서 위치 확인
- PDF 암호, 손상, 빈 페이지 확인
- 이미지 파일 크기 읽기 실패 확인
- 해상도 72~600 dpi 확인
- 폴더 삽입은 실패 파일을 로그에서 확인

### 14.12 그림 도구가 실패함

- 그림 개체 선택 여부 확인
- 표 셀 안 그림인지 확인
- 회전 뒤 셀 맞춤 실패 시 그림과 셀 상태 확인
