# BUFS 한글 편집기 용어 설명 초안

이 문서는 사용설명서 본문에서 반복해서 나오는 용어를 행정직원이 이해하기 쉬운 말로 정리하기 위한 초안이다. 최종 사용설명서에서는 각 용어를 필요한 위치에 짧게 다시 설명하고, 이 문서는 부록 또는 별도 용어 사전으로 제공한다.

## 한글 문서와 앱 동작 관련 용어

### 대상 문서

앱이 현재 작업하려고 연결한 한글 문서다.

한글 창을 여러 개 열어 두면 사용자가 생각한 문서와 앱이 연결한 문서가 다를 수 있다. 작업 전 `상태` 탭에서 대상 문서를 확인하는 것이 좋다.

### 선택 영역

한글 문서에서 사용자가 마우스나 키보드로 선택한 부분이다.

BUFS 한글 편집기의 대부분 기능은 문서 전체가 아니라 선택 영역에 적용된다. 예를 들어 본문 일부를 선택하고 `일괄처리`를 누르면 선택한 문단만 정리된다.

### 커서 위치

한글 문서에서 현재 글자가 입력될 위치다.

로고 삽입, 새 번호 개체 넣기, 표지 삽입처럼 무언가를 새로 넣는 기능은 선택 영역보다 커서 위치가 중요할 수 있다.

### 실행취소

방금 한 작업을 되돌리는 기능이다.

한글의 `Ctrl+Z` 또는 앱의 실행취소 기능을 사용할 수 있다. 중요한 문서에서는 큰 작업을 하기 전에 저장해 두는 것이 안전하다.

### HWPX 형식

한글 문서 형식 중 하나다. 파일 확장자는 `.hwpx`다.

BUFS 한글 편집기는 스타일 목록 확인과 양식 처리를 할 때 `.hwpx` 형식에서 더 안정적으로 동작한다. `.hwp` 문서에서 스타일 적용이 이상하면 한글에서 `.hwpx`로 다른 이름 저장한 뒤 다시 연결한다.

## 스타일 관련 용어

### 스타일

한글 문서에서 글자 모양, 문단 모양, 번호 모양 등을 이름으로 저장해 둔 서식이다.

예를 들어 `본문1`, `표내용-중간`, `[표/그림] 캡션` 같은 이름이 스타일이다. 앱은 이 스타일 이름을 찾아 현재 문서에 적용한다.

### 문단 스타일

한 문단 전체에 적용되는 스타일이다.

문단 스타일은 보통 줄 간격, 들여쓰기, 정렬, 문단 번호, 글자 기본 모양을 함께 정한다. 보고서의 제목, 본문, 표 안 내용처럼 문단 단위로 모양을 맞출 때 사용한다.

예:

- `바탕글`
- `본문1`
- `본문2`
- `표내용-중간`
- `[표/그림] 캡션`

### 글자 스타일

문단 전체가 아니라 선택한 글자 일부에만 적용되는 스타일이다.

예를 들어 `목적: 사업 추진 방향을 정리함`이라는 문장에서 `목적`만 굵게 만들고 싶을 때 글자 스타일을 사용한다.

예:

- `본문-굵게`
- `표내용-굵게`

### 스타일 세트

문서 유형별로 사용할 스타일과 자동 처리 규칙을 묶어 둔 설정이다.

예를 들어 보고서와 공문은 쓰는 스타일이나 번호 체계가 다를 수 있다. 이때 `보고서용`, `일반보고용`, `공문용`처럼 스타일 세트를 나누면 문서 유형에 맞게 설정을 바꿔 사용할 수 있다.

### 활성 스타일 세트

현재 앱에서 선택되어 있는 스타일 세트다.

`스타일/정리` 탭의 스타일 세트 선택 상자에서 고른 세트가 활성 스타일 세트다. `일괄처리`, 자동 굵게, 표 안 스타일 구분 등은 활성 스타일 세트의 설정을 기준으로 동작한다.

### 스타일 이름

한글 문서 안에 저장된 스타일의 이름이다.

앱의 설정에 `본문1`이라는 스타일이 있어도, 현재 한글 문서에 `본문1` 스타일이 없으면 적용이 실패할 수 있다. 따라서 앱 설정의 스타일 이름과 실제 한글 문서의 스타일 이름이 같아야 한다.

목록에 없던 새 스타일을 쓰려면 한글 문서에 새 스타일을 만들고 앱의 스타일 목록에도 같은 이름으로 추가한다. 이름이 다르면 앱이 다른 스타일로 인식한다.

스타일 이름을 맞추려면 한글의 스타일 불러오기에서 설치 폴더의 `bufs/templates`에 있는 양식 파일을 선택해 스타일을 가져오거나 앱에서 보고양식을 현재 문서에 불러온다. 양식 파일을 직접 열어 작업하면 원본 양식을 잘못 편집할 수 있으므로 주의한다. 한글에서 스타일을 직접 추가하거나 편집해야 할 때는 한글 2024 도움말을 참고한다.

- [스타일 추가하기](https://help.hancom.com/hoffice130_assistant/ko-KR/Hwp/index.htm#t=format%2Fstyle%2Fstyle(new).htm)
- [스타일 편집하기](https://help.hancom.com/hoffice130_assistant/ko-KR/Hwp/index.htm#t=format%2Fstyle%2Fstyle(edit).htm)
- [스타일 적용하기](https://help.hancom.com/hoffice130_assistant/ko-KR/Hwp/index.htm#t=format%2Fstyle%2Fstyle(apply).htm)

### 스타일 목록 순서

앱 화면에서 스타일 버튼 또는 목록이 보이는 순서다.

순서를 바꾸면 자주 쓰는 스타일을 위에 둘 수 있다. 다만 이 순서는 화면 표시 순서일 뿐, 한글 문서 안의 스타일 자체를 바꾸는 것은 아니다.

## 스타일 세트 관리 용어

### 표 체크박스

이 스타일이 표 안에서 쓰는 스타일인지 표시하는 설정이다.

표 체크가 된 스타일은 표 안 텍스트를 정리할 때 우선 사용된다. 예를 들어 표 안에서 `목적:` 앞부분을 굵게 만들 때는 본문용 굵게가 아니라 표용 굵게 스타일이 필요할 수 있다.

예:

- `표내용-중간`: 표 체크 권장
- `표내용-왼쪽`: 표 체크 권장
- `표내용-굵게`: 표 체크 권장

### 캡션 체크박스

이 스타일이 표나 그림의 캡션에 쓰는 스타일인지 표시하는 설정이다.

`캡션원클릭` 기능은 캡션을 만든 뒤 어떤 스타일을 적용할지 찾아야 한다. 이때 캡션 체크가 된 스타일을 캡션 스타일 후보로 본다.

예:

- `[표/그림] 캡션`: 캡션 체크 권장

### 식별자 또는 개요 표시자

붙여넣은 문장 맨 앞에 있는 기호나 약속어다.

앱은 식별자를 보고 어떤 문단 스타일을 적용할지 판단한다. 사용설명서에서는 `식별자`와 `개요 표시자`를 같은 뜻으로 쓴다.

예:

- `ㅇ`
- `○`
- `-`
- `∙`
- `표점`
- `표삼각`

예시:

```text
ㅇ 추진 배경
- 세부 추진 내용
표점 표 안 하위 항목
```

### 역할

자동 굵게 규칙이 사용할 글자 스타일을 찾기 위한 이름표다.

글자 스타일 이름은 기관이나 문서마다 다를 수 있다. 그래서 앱은 “이 스타일은 본문 굵게용이다”, “이 스타일은 표 안 굵게용이다”라는 역할 표시를 사용한다.

기본 역할:

- `body_bold`: 본문에서 사용할 굵게 글자 스타일
- `table_bold`: 표 안에서 사용할 굵게 글자 스타일

예:

- `본문-굵게` 스타일에 `body_bold` 역할 지정
- `표내용-굵게` 스타일에 `table_bold` 역할 지정

역할은 문단 스타일이 아니라 글자 스타일에 지정해야 한다. 자동 굵게 규칙은 글자 스타일만 적용할 수 있다.

스타일 세트 관리 화면의 `규칙` 탭에서도 같은 역할 이름을 골라야 한다. 예를 들어 규칙이 `body_bold`를 쓰도록 되어 있으면 같은 스타일 세트 안에 `body_bold` 역할을 가진 글자 스타일이 있어야 한다. 설정에서 `text_bold` 같은 다른 이름을 쓰기로 했다면 글자 스타일의 역할과 규칙의 글자 역할을 같은 이름으로 맞춘다.

### 번호 그룹

번호가 서로 섞이지 않게 나누는 묶음이다.

본문 번호와 표 안 번호는 서로 이어지면 안 되는 경우가 많다. 그래서 번호 그룹을 나누어 “본문 번호는 본문끼리”, “표 안 번호는 표끼리” 판단하게 한다.

기본 그룹:

- `body`: 본문 번호용
- `table`: 표 안 번호용

### 번호 단계

번호 또는 개요의 깊이다.

1단계는 큰 항목, 2단계는 하위 항목, 3단계는 더 하위 항목처럼 이해하면 된다.

예:

```text
1. 큰 항목        -> 1단계
  가. 하위 항목   -> 2단계
    1) 세부 항목  -> 3단계
```

앱에서 번호 단계가 맞아야 하위 번호를 다시 시작할지 판단할 수 있다.

### 상위 개요 뒤 새 번호

상위 단계가 새로 나오면 하위 번호를 다시 시작하게 하는 설정이다.

예를 들어 아래처럼 큰 항목이 바뀔 때 하위 항목을 다시 1번부터 시작하고 싶을 때 사용한다.

```text
1. 추진 배경
  1) 현황
  2) 문제점

2. 추진 계획
  1) 세부 일정
  2) 담당 부서
```

이 설정이 꺼져 있으면 `2. 추진 계획` 아래 하위 번호가 앞 항목에 이어서 3번부터 시작할 수 있다.

## 일괄처리 관련 용어

### 일괄처리

선택한 본문이나 표 안 텍스트를 한 번에 정리하는 기능이다.

일괄처리를 하기 전에는 `스타일/정리` 탭의 `관리`에서 식별자를 넣어야 한다. 식별자는 `ㅇ`, `○`, `-`, `표점`처럼 문장 앞에서 스타일을 구분하는 표시다.

일괄처리는 보통 다음 작업을 함께 한다.

- 식별자 또는 개요 표시자에 맞는 문단 스타일 적용
- 첫머리 괄호 키워드 굵게
- 콜론 앞 키워드 굵게
- 마크다운 굵게 표시 제거
- 본문과 표 안 텍스트를 구분하여 다른 스타일 적용

### 첫머리 괄호 키워드

문장 앞쪽에 있는 괄호 묶음 키워드다.

예:

```text
ㅇ (배경) 외국인전임교원 지원 제도를 점검함.
```

앱은 `(배경)` 부분을 찾아 굵게 처리할 수 있다.

### 첫머리 콜론 앞

문장 앞쪽에서 콜론 앞에 있는 키워드다.

예:

```text
목적: 신청 절차를 간소화하고자 함.
```

앱은 `목적` 부분을 찾아 굵게 처리할 수 있다.

### 마크다운 굵게

텍스트 앞뒤에 `**`를 붙여 굵게를 표시하는 방식이다.

예:

```text
**중요 내용**
```

앱은 `**` 표시는 제거하고 안쪽 텍스트에 한글 글자 스타일을 적용할 수 있다.

### 소숫점 지정

앱 화면에서 소수점 자리를 정하는 기능 이름이다.

선택한 숫자를 지정한 자리수로 반올림, 올림, 버림 처리한다. 쉼표를 체크하면 결과에 천 단위 쉼표를 함께 넣는다.

### 단위 변환

선택한 숫자의 단위를 원, 천원, 백만원 등으로 바꾸는 기능이다.

숫자에 곱하거나 나누는 버튼과 목표 단위를 고르는 버튼이 있다. 변환 대상이 아닌 단위가 섞여 있으면 잘못 바꾸지 않도록 중단할 수 있다.

## 표 편집 관련 용어

### 표내용 스타일

표 안 문단에 적용하는 스타일이다.

예:

- `표내용-왼쪽`
- `표내용-중간`
- `표내용-오른쪽`
- `표내용-개요번호-레벨1`
- `표내용-개요번호-레벨2`

표 안에서는 본문 스타일보다 표내용 스타일을 쓰는 것이 보통 더 안정적이다.

앱의 `표 편집` 탭에 보이는 표내용 스타일 버튼은 스타일 세트에서 `표`가 체크된 문단 스타일을 기준으로 나타난다. 표 안에서 쓸 스타일을 추가했는데 버튼에 보이지 않으면 해당 스타일의 `표` 체크를 확인한다.

### 색상 팔레트

앱에서 자주 쓰는 색을 이름으로 저장해 둔 목록이다.

예:

- 노랑
- 진회색
- 회색
- 연회색
- 검정
- 흰색
- 셀배경

색상 팔레트는 셀 배경색, 글자색, 제목셀 배경색 등에 사용된다.

### 선 프리셋

표 테두리 선의 모양을 미리 정해 둔 설정이다.

예:

- 얇은 선
- 굵은 선
- 이중 선
- 점선
- 선 없음

선 프리셋에는 선 굵기, 선 종류, 선 색상이 포함된다.

### 제목셀

표의 첫 줄처럼 제목 역할을 하는 셀이다.

제목셀 자동화는 제목셀에 배경색, 글자색, 문단 스타일, 글자 스타일, 테두리 조합을 한 번에 적용한다.

### 셀 안 여백

셀 경계선과 글자 사이의 간격이다.

셀 안 여백이 너무 작으면 글자가 선에 붙어 보이고, 너무 크면 표가 답답해 보일 수 있다.

### 표 바깥 여백

표와 본문 사이의 간격이다.

보고서에서는 표 아래쪽 간격을 일정하게 두면 다음 문단과 표가 덜 붙어 보인다.

### 너비맞추기

현재 표의 너비를 페이지 폭에 맞추는 기능이다.

표가 너무 좁거나 넓게 들어갔을 때 사용한다.

### Markdown 표

세로 막대 `|`로 열을 나누어 표현한 텍스트 표다.

예:

```text
| 구분 | 내용 |
| --- | --- |
| A | 첫 번째 내용 |
| B | 두 번째 내용 |
```

앱은 Markdown 표를 한글 표로 붙여넣고, 기본 표 스타일을 적용할 수 있다.

## 캡션 관련 용어

### 캡션

표나 그림에 붙는 제목이다.

예:

- `[표 1-1] 부서별 제출 현황`
- `[그림 2-1] 업무 처리 흐름`

한글에서는 표나 그림 개체에 캡션을 붙이면 번호 관리와 위치 관리가 쉬워진다.

### 캡션원클릭

선택한 캡션 후보 문장을 실제 표 캡션으로 옮기는 기능이다.

앱은 선택한 문장을 읽고, 근처 표를 찾아 캡션을 만든 뒤 캡션 스타일을 적용한다.

표 캡션을 만들 때는 한글의 표 번호 개체도 함께 들어간다. 번호를 붙이면 안 되는 보조 표가 표 번호로 잡히면 뒤쪽 표 번호가 밀릴 수 있다.

### 번호종류

선택한 표나 그림 개체를 표 번호, 그림 번호, 번호 없음 중 어디에 넣을지 정하는 기능이다.

표 번호에서 제외해야 하는 표는 `번호종류`에서 `없음`으로 바꾼다. 표 안의 작은 보조 표나 배치용 표처럼 캡션 번호에 들어가면 안 되는 표에 사용한다.

### 캡션 후보 문장

캡션으로 만들기 위해 사용자가 미리 작성한 문장이다.

예:

```text
[표 5.4-8] 샘플표제통
```

이 문장을 선택하고 `캡션원클릭`을 실행하면 표 캡션으로 변환할 수 있다.

기본 설정에서는 대괄호 안 첫 낱말이 `표` 또는 `그림`이어야 한다. 번호 앞부분에는 하이픈 `-`이 있어야 한다.

인식하기 쉬운 예:

```text
[표 1-1] 부서별 제출 현황
[표 5.4-8] 샘플표제통
[그림 2.4-1] 학사관리 체계 개선 실적
```

기본 설정에서 인식하기 어려운 예:

```text
표 1-1 부서별 제출 현황
[표 1] 부서별 제출 현황
[표 1.1] 부서별 제출 현황
[사진 1-1] 행사 사진
```

### 캡션 인식 규칙

어떤 문장을 캡션 후보로 볼지 정하는 규칙이다.

기본적으로 `[표 ...] 제목`, `[그림 ...] 제목` 형식을 인식한다. 부서에서 쓰는 캡션 형식이 다르면 이 규칙을 조정해야 한다.

### 앞부분 템플릿

캡션에서 번호 앞쪽을 어떻게 만들지 정하는 설정이다.

예를 들어 `[표 5.4-` 같은 부분을 만드는 데 사용된다.

### 뒷부분 템플릿

캡션 번호 뒤에 제목을 어떻게 붙일지 정하는 설정이다.

예를 들어 `] 샘플표제통` 같은 부분을 만드는 데 사용된다.

### 인식 테스트

캡션 샘플 문장이 현재 규칙으로 어떻게 나뉘는지 확인하는 기능이다.

캡션원클릭이 실패할 때는 먼저 인식 테스트에서 앞부분과 뒷부분이 예상대로 나오는지 확인한다.

## 쪽 편집 관련 용어

### 새 번호 개체

한글에서 표 번호, 그림 번호 같은 자동 번호를 새로 넣는 기능이다.

번호를 넣고 싶은 위치에 커서를 둔 상태에서 사용해야 한다.

## 문장 정리 관련 용어

### 문단 새 번호

현재 문단의 번호를 새 번호로 시작하게 하는 기능이다.

앱에서는 `스타일/정리` 탭의 `새 번호` 버튼으로 실행한다. 커서가 있는 문단 하나에 수동으로 적용한다.

문단 번호가 적용된 문단에서 사용해야 하며, 번호가 없는 일반 문단에서는 실패할 수 있다. 여러 문단에서 같은 문제가 반복되면 하위 스타일의 `상위 개요 뒤 새 번호` 설정을 확인한다.

### 이어서

현재 문단 번호를 앞 번호에 이어가게 하는 기능이다.

문단 번호가 실수로 다시 1번부터 시작했을 때 사용한다. 앱에서는 `스타일/정리` 탭의 `이어서` 버튼으로 실행한다.

### 괄호 씌우기

선택한 규정명이나 문서명을 낫표 괄호로 감싸는 기능이다.

앱에서는 `스타일/정리` 탭의 `「 」 씌우기` 버튼으로 실행한다. 예를 들어 `교원 인사 규정`을 선택하고 실행하면 `｢교원 인사 규정｣`처럼 바뀐다.

여러 줄이나 표 셀 여러 칸을 선택하면 서식 보존이 불안정할 수 있으므로 한 줄 안의 필요한 글자만 선택한다.

### 줄바꿈정리

선택한 글에서 불필요하게 들어간 수동 줄바꿈과 중복 띄어쓰기를 정리하는 기능이다.

PDF나 웹페이지에서 복사한 내용이 줄마다 끊겨 있을 때 사용한다. 목록처럼 보이는 줄이나 빈 줄은 가능한 한 유지한다.

### 기호제거

선택한 문단 앞에 직접 입력한 개요 기호를 지우는 기능이다.

예를 들어 `ㅇ`, `○`, `-`, `ㆍ`, `※` 같은 기호를 지운다. 한글 문단 번호 모양도 함께 정리하려고 시도한다.

## 특수문자 관련 용어

### 글자 겹치기

한글의 글자 겹치기 기능을 이용해 두 문자를 겹쳐 보이게 만든 글자다.

네모와 체크 표시를 겹쳐 체크박스처럼 만들거나 숫자를 네모 안에 넣을 때 사용한다.

앱의 `특수문자` 탭에서 넣을 수 있으며 입력할 위치에 커서를 둔 뒤 사용한다.

### 체크박스

문서 안에 넣는 체크 표시 문자 또는 체크 표시가 들어간 네모 문자다.

일반적인 체크박스 문자와 글자 겹치기로 만든 체크박스가 있을 수 있다.

### 겹치기글자

글자 겹치기와 같은 뜻으로 쓰는 말이다.

## 양식과 그림 관련 용어

### 표지 템플릿

표지를 만들 때 기본 모양으로 사용하는 한글 양식 파일이다.

앱은 표지 템플릿 안의 자리표시자를 제목, 날짜, 부서명으로 바꾼 뒤 문서에 삽입한다.

### 자리표시자

나중에 실제 내용으로 바뀔 표시 문구다.

예:

- `{{문서제목}}`
- `{{날짜}}`
- `{{부서명}}`

### 보고양식

보고서 본문을 시작할 때 불러오는 기본 양식이다.

제목, 날짜, 부서명 등을 입력해 일정한 보고서 형식으로 시작할 수 있다.

### 대제목 번호박스

큰 제목 앞에 번호가 들어간 상자 양식이다.

앱은 현재 문서 안의 번호박스를 읽어 다음 번호를 계산하려고 한다. 기존 번호박스를 직접 고쳤거나 양식이 다르면 번호가 예상과 다를 수 있다.

### 증빙 PDF

보고서 뒤에 붙이는 PDF 증빙 자료다.

앱은 PDF를 이미지로 바꾼 뒤 증빙 양식 안에 넣는다. 암호가 걸린 PDF, 손상된 PDF, 페이지가 없는 PDF는 실패할 수 있다.

### 그림 셀 맞춤

선택한 그림을 현재 표 셀 크기에 맞추는 기능이다.

그림 개체를 선택한 상태에서 실행해야 한다. 표 셀 밖의 그림에서는 셀 크기를 읽지 못할 수 있다.

### 로고 삽입

앱에 등록된 BUFS 로고 이미지를 현재 커서 위치에 넣는 기능이다.

이미지는 가능한 한 원래 비율을 유지해서 삽입한다.

## 문제 해결에서 자주 나오는 표현

### 현재 문서에 같은 이름의 스타일이 없음

앱 설정에는 스타일 이름이 있지만, 실제 한글 문서에는 그 이름의 스타일이 없다는 뜻이다.

해결 방법:

- 올바른 양식 문서를 사용한다.
- 스타일 세트에 등록한 이름을 실제 한글 문서의 스타일 이름과 맞춘다.
- 필요한 스타일을 한글 문서에 먼저 가져온다.

### 표 선택 상태가 아님

표 기능을 실행했지만 앱이 현재 표 또는 셀을 찾지 못했다는 뜻이다.

해결 방법:

- 표 안에 커서를 둔다.
- 셀을 선택한다.
- 표 개체를 선택한다.
- 복잡한 병합 셀에서는 일부 기능이 실패할 수 있으므로 단순한 표에서 먼저 테스트한다.

### 글자 역할을 찾지 못함

자동 굵게 규칙이 사용할 글자 스타일을 찾지 못했다는 뜻이다.

해결 방법:

- 글자 스타일이 스타일 세트에 등록되어 있는지 확인한다.
- 본문 굵게 스타일에는 `body_bold` 역할을 지정한다.
- 표 굵게 스타일에는 `table_bold` 역할을 지정한다.
- 굵게용 스타일의 종류가 `글자`인지 확인한다.
- `규칙` 탭에서 해당 규칙의 글자 역할이 실제 글자 스타일의 역할과 같은지 확인한다.

### 번호가 이어짐

새 항목 아래에서 번호가 다시 시작되지 않고 앞 번호에 이어지는 상태다.

해결 방법:

- 번호 그룹이 같은지 확인한다.
- 번호 단계가 맞는지 확인한다.
- 하위 단계 스타일에 `상위 개요 뒤 새 번호`가 켜져 있는지 확인한다.
