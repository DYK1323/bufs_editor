# 5.5 문단 탭

문단 탭은 한 줄 안에서 왼쪽 제목과 오른쪽 표시를 가지런히 맞출 때 사용합니다. 표 제목 오른쪽에 단위를 붙이거나, 목차처럼 제목과 쪽 번호 사이에 점선을 넣을 때 편합니다.

주요 버튼은 다음과 같습니다.

| 버튼 | 언제 사용하나요 |
| --- | --- |
| `오른쪽 자동탭` | 표 제목 오른쪽에 `(단위: 천원)` 같은 단위 표기를 붙이거나, 제목 줄 오른쪽에 `별첨자료`, `증빙자료` 같은 표시를 붙일 때 사용합니다. |
| `목차⋯⋯1` | 목차처럼 왼쪽 제목과 오른쪽 쪽 번호 사이를 점선으로 연결할 때 사용합니다. |

다음 예시는 표 제목 줄 오른쪽에 단위 표기를 붙이는 `오른쪽 자동탭` 사용 모습입니다.

![오른쪽 자동탭 예시](../assets/gifs/오른쪽 자동탭.gif)

문단 탭은 현재 문단이나 선택한 문단에 적용됩니다. 표 안에서 실행하면 선택한 셀의 안쪽 폭을 기준으로 맞추려고 하고, 일반 본문에서는 쪽의 본문 폭을 기준으로 맞추려고 합니다.
