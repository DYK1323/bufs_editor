# BUFS 한글 편집기 사용 안내

## 준비물

- Windows PC
- 한컴오피스 한글 2024 또는 호환 버전

Python은 설치하지 않아도 됩니다.

## 실행

1. 배포받은 `BUFS-HWP-Editor` 폴더를 원하는 위치에 풉니다.
2. 한글에서 편집할 문서를 먼저 엽니다.
3. `BUFS-HWP-Editor.exe`를 더블클릭합니다.
4. 필요하면 `install-shortcut.ps1`을 PowerShell에서 실행해 바탕화면 바로가기를 만듭니다.

PowerShell 스크립트 실행이 막히면 아래 명령을 현재 PowerShell 창에서만 실행한 뒤 다시 시도하세요.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\install-shortcut.ps1
```

## 기본 사용 흐름

- `스타일/정리`: 문단 스타일, 문장 정리, 숫자/소숫점/단위/날짜 정리
- `표 편집`: 셀 배경색, 글자색, 표 스타일, 제목셀, 마크다운 표 변환
- `표지/로고`: 표지 만들기, 로고 삽입
- `상태`: 한글 연결 상태와 대상 문서 확인

## 문제 해결

### 앱이 한글을 찾지 못함

- 한글 문서를 먼저 열고 다시 실행하세요.
- 앱의 `상태` 탭에서 `한글 다시 연결`을 눌러보세요.

### 표지/로고/테스트 문서 열기가 실패함

한글의 파일 경로 보안 모듈 설정이 필요한 PC일 수 있습니다. 이 설정은 후속 설치 도구에서 자동 점검하도록 준비할 예정입니다.

### 보안 프로그램이 실행 파일을 막음

처음 만든 내부 배포본은 코드 서명이 없어서 Windows 또는 백신이 경고할 수 있습니다. 신뢰할 수 있는 내부 배포 경로에서 받은 파일인지 확인한 뒤 실행하세요.
