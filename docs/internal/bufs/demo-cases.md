# BUFS HWP Editor 시연 케이스

이 파일은 한글 문서에 그대로 붙여넣고 앱 기능을 시연하기 위한 샘플입니다.
각 블록을 필요한 만큼 선택한 뒤 앱 버튼을 실행하세요.

## 1. 표지 만들기

아래 블록을 선택한 뒤 `양식/로고` 탭의 `선택 내용으로 표지 만들기`를 누릅니다.

### 1-1. 표지: 날짜 생략

```text
제목: 2026학년도 대학혁신지원사업 운영 결과 보고
부서: 대학성과분석센터
```

예상: 날짜가 오늘 연월 형식으로 들어갑니다. 예: `2026. 7.`

### 1-2. 표지: 오늘 키워드

```text
제목: 비교과 프로그램 운영 현황
날짜: 오늘
부서: 교육혁신처
```

### 1-3. 표지: 오늘 플레이스홀더

```text
제목: 외국인전임교원 지원 제도 점검
날짜: {{오늘}}
부서: 교무처
```

### 1-4. 표지: 2줄 입력

```text
2026학년도 월급루팡 계획안
일하다미쳐내가
```

## 2. 보고양식 불러오기

아래 블록을 선택한 뒤 `양식/로고` 탭의 `보고양식 불러오기`를 누릅니다.

### 2-1. 보고양식: 날짜 생략

```text
제목: 2026학년도 대학혁신지원사업 자체점검 결과 보고
부서: 대학성과분석센터
```

예상: 날짜가 오늘 연월일 형식으로 들어갑니다. 예: `2026. 7. 22.`

### 2-2. 보고양식: 오늘 키워드

```text
제목: 외국인전임교원 처우 개선 검토
부서: 교무처
날짜: 오늘
```

### 2-3. 보고양식: 오늘 플레이스홀더

```text
제목: 비교과 교육과정 운영 현황 보고
부서: 교육혁신처
날짜: {{오늘}}
```

### 2-4. 보고양식: 명시 날짜

```text
제목: 2026학년도 2학기 운영계획 보고
부서: 기획처
날짜: 2026. 8. 3.
```

## 3. 일괄처리: 본문 개요와 굵게 규칙

아래 블록을 한글 본문에 붙여넣고 전체를 선택한 뒤 `스타일` 탭의 `일괄처리`를 누릅니다.

```text
ㅇ (배경) 외국인전임교원이 국내정착을 지원하기 위하여 매월 주거보조비를 지급하고 있음.
ㅇ 목적: 신임교원의 조기 적응과 안정적인 교육활동을 지원하고자 함.
○ (운영 방향) 제도 운영 기준을 정비하고 신청 절차를 간소화하고자 함.
원 추진 내용: 신청서 접수, 증빙자료 확인, 지급 대상 검토를 순차적으로 진행함.
- 세부 계획: 부서별 담당자를 지정하고 월별 점검표를 작성함.
ㆍ (유의 사항) 괄호 안 키워드는 괄호까지 굵게 적용되어야 함.
```

확인 포인트:
- 개요 식별자에 맞는 문단 스타일이 적용되는지 확인합니다.
- `(배경)`, `(운영 방향)`, `(유의 사항)`은 괄호까지 굵게 적용되어야 합니다.
- `목적`, `추진 내용`, `세부 계획`은 콜론 앞까지만 굵게 적용되어야 합니다.

## 4. 일괄처리: 이미 스타일이 적용된 본문에서 굵게만 재적용

아래 블록을 본문 스타일이 적용된 문단으로 만든 뒤 다시 선택하고 `일괄처리`를 누릅니다.

```text
(항공료) 계약에 근거하여 해외에서 입국하는 신임교원에게는 부산까지의 편도항공료를 지급하고 있음. 또한 4학기 이상 근무한 교원에게는 귀국항공료를 지원함.
목적: 지원 기준을 명확히 하여 예산 집행의 예측 가능성을 높이고자 함.
```

확인 포인트:
- 개요 식별자가 없어도 첫머리 괄호 키워드와 콜론 앞 키워드에 굵게가 적용되는지 확인합니다.
- 문장 뒤쪽의 `(교환교수는 2학기 이상)` 같은 괄호가 있더라도 전체 문장이 굵게 변하지 않아야 합니다.

## 5. 마크다운 굵게 흔적 제거

아래 블록을 붙여넣고 `일괄처리`를 누릅니다.

```text
ㅇ **(항공료)** 계약에 근거하여 해외에서 입국하는 신임교원에게 항공료를 지급하고 있음.
ㅇ 지급 기준: **신임교원 및 교환교수**의 계약 조건에 따라 지급함.
```

확인 포인트:
- `**` 표시는 제거되고, 표시 안쪽 텍스트에는 굵게가 적용되어야 합니다.

## 6. 표 시연: 마크다운 표

아래 표를 한글에 붙여넣어 표로 만들거나, 내용을 참고해 한글 표를 만든 뒤 표 편집 기능을 테스트합니다.

| 구분 | 먼저 볼 분석예시 | 읽을 개수 |
| --- | --- | --- |
| 월별 자료 입력 안내 | 표점 (유형) `gw_docs/analysis/공문유형_분석.md`의 A유형, 최신 같은 월 문서 | 1~2개 |
| 월별 자료 제출 | 표삼각 `scripts/academyinfo/build_gongsi_submission_markdown.py` 실행 | 0개 |
| 부서별 담당자 확인자 제출 요청 | 최신 **부서별 담당자 확인자 제출 요청.md** | 1~2개 |
| 수시항목 자료 입력 안내 | 수시항목 자료 입력 안내(N월).md 중 가장 가까운 월 | 1~2개 |
| 졸업생 진학취업 별도 공시 안내 | `scripts/academyinfo/build_gongsi_special_markdown.py` 실행 | 0개 |

## 7. 표 시연: TSV 셀 붙여넣기용

아래 코드블록 안의 내용을 복사해 한글 표 또는 스프레드시트에 붙여넣습니다.

```text
구분	먼저 볼 분석예시	읽을 개수
월별 자료 입력 안내	표점 (유형) `gw_docs/analysis/공문유형_분석.md`의 A유형, 최신 같은 월 문서	1~2개
월별 자료 제출	표삼각 `scripts/academyinfo/build_gongsi_submission_markdown.py` 실행	0개
부서별 담당자 확인자 제출 요청	최신 **부서별 담당자 확인자 제출 요청.md**	1~2개
수시항목 자료 입력 안내	수시항목 자료 입력 안내(N월).md 중 가장 가까운 월	1~2개
졸업생 진학취업 별도 공시 안내	`scripts/academyinfo/build_gongsi_special_markdown.py` 실행	0개
```

표 안에서 확인할 기능:
- 여러 셀을 선택하고 `일괄처리`를 눌렀을 때 표용 문단/글자 스타일이 적용되는지 확인합니다.
- 첫머리 괄호, 콜론 앞 텍스트, 마크다운 굵게 흔적이 표용 굵게 스타일로 적용되는지 확인합니다.
- `표내용 스타일`, `표제목 스타일`, `번호종류` 버튼을 각각 테스트합니다.

## 8. 캡션 원클릭

아래 문장을 선택한 뒤 바로 아래 표를 선택하거나 표 근처에 커서를 두고 `캡션원클릭`을 누릅니다.

```text
[표 5.4-8] 샘플표제통
```

확인 포인트:
- 표 캡션이 만들어지고 캡션 스타일이 적용되는지 확인합니다.
- 번호종류를 `표` 또는 `그림`으로 바꾸면 캡션의 번호 개체 종류도 함께 바뀌는지 확인합니다.

## 9. 괄호 씌우기

아래 문장에서 `핵심 키워드`만 선택하고 괄호 씌우기 버튼을 누릅니다.

```text
이 문장에서는 핵심 키워드를 표준 괄호로 감싸야 합니다.
```

아래 문장에서 `「기존 괄호」` 전체 또는 안쪽 텍스트를 선택하고 괄호 씌우기 버튼을 누릅니다.

```text
이 문장에서는 「기존 괄호」를 앱에서 정한 표준 괄호로 바꿔야 합니다.
```

## 10. 날짜 정규화

아래 블록을 선택한 뒤 날짜 정규화 버튼을 테스트합니다.

```text
2026년 7월 22일 회의 개최
2026.7.22. 결과 보고
2026-07-22 자료 제출
2026. 7. 2. 최종 확인
```

## 11. 숫자 정리

아래 블록을 선택한 뒤 쉼표 넣기, 쉼표 빼기, 단위 변환 버튼을 테스트합니다.

```text
총사업비는 1200000원이며, 집행액은 987654원입니다.
전년도 예산은 1,250,000원이고 올해 예산은 1350000원입니다.
인건비는 2500천원, 운영비는 3백만원입니다.
```

확인 포인트:
- 날짜나 학년도 숫자는 숫자 정리에서 의도치 않게 바뀌지 않아야 합니다.
- 쉼표 위치가 이상한 숫자는 경고가 떠야 합니다.
