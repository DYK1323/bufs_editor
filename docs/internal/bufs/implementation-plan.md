# 한글 문서 스타일 자동화 도구 구현 계획

## 목표

한글(HWP/HWPX) 문서 디자인 작업을 빠르게 하기 위한 가벼운 Windows 데스크톱 자동화 도구를 만든다.

1차 버전은 다음 세 가지에 집중한다.

1. 미리 만들어둔 한글 스타일을 빠르게 적용한다.
2. 표 셀의 제목셀/선/색/스타일을 한 번에 정리한다.
3. 오래된 문서에서 자주 보이는 줄바꿈, 공백, 숫자 쉼표 문제를 선택 영역 기준으로 정리한다.

## 기준 자료

- `bufs/templates/보고서 본문 서식.hwpx`
  - 1차 스타일 라이브러리 파일이다.
  - `본문`, `개요`, `표제목`, `표내용`, `캡션`, `표 아래 주석` 계열 스타일이 들어 있다.
  - 도구는 이 파일에서 스타일 이름을 읽어 UI 버튼/목록의 기준으로 사용한다.
- `bufs/logos/`
  - 우리대학 로고 파일을 넣어둘 폴더다.
  - 1차 버전에서는 로고 삽입 기능을 구현하지 않더라도, 이후 확장을 위해 자산 구조를 미리 정한다.
  - 기본 로고 타입 후보는 네 가지로 둔다.
    - 기본형
    - 가로형
    - 심볼형
    - 흑백형
  - 실제 로고 폴더명은 기관에서 받은 파일명/분류명을 그대로 둘 수 있다.
  - 구현은 고정 폴더명에 의존하지 않고 `bufs/logos/` 아래 이미지 파일을 재귀적으로 읽는다.
- `bufs/templates/표지.hwpx`
  - 표지 자동 생성용 기본 템플릿 파일이다.
  - 자리표시자 기준:
    - `{{문서제목}}`
    - `{{날짜}}`
    - `{{부서명}}`
  - 대외비 표시는 사용자가 선택한 값에 따라 유지하거나 제거한다.
- `bufs/표지.hwp`
  - 같은 표지의 원본 또는 호환용 파일로 보관한다.
  - 자동화 기준 파일은 가능하면 `bufs/templates/표지.hwpx`로 둔다.

## 권장 기술 방향

- 기존 `범피스`처럼 가벼운 방식으로 만든다.
  - Python
  - Tkinter 또는 단순한 네이티브 UI
  - pywin32 / COM 자동화로 한글 제어
  - PyInstaller로 패키징
- 1차 버전에서는 WebView 기반 UI를 피한다.
- NumPy, Pillow, WebView2 같은 큰 의존성은 꼭 필요한 기능이 확인되기 전까지 넣지 않는다.

## 배포 전략

- 개발 환경에는 `pywin32`가 필요하다.
  - Python 코드에서는 `win32com.client`, `pythoncom`을 사용한다.
- 최종 사용자에게 Python이나 pywin32 설치를 요구하지 않는 것을 목표로 한다.
- 배포본은 PyInstaller로 빌드해 `pywin32` 런타임을 함께 포함한다.
- 사용자의 PC에는 한컴오피스 한글이 설치되어 있어야 한다.
- 실행 시 한글 COM 객체(`HWPFrame.HwpObject`)가 등록되어 있지 않으면 명확한 안내 메시지를 보여준다.
- 개발/검증용으로는 `bufs` 내부에 가상환경을 만들 수 있다.
  - 예: `bufs/.venv`
  - 설치 후보: `pywin32`
- 실제 배포 패키지에는 `bufs/.venv`를 포함하지 않는다.

## 우선순위

1. 스타일 적용
2. 표 디자인 자동화
3. 정리 기능

## 기본 UI 구조

탭은 세 개로 구성한다.

- `스타일`
- `표`
- `정리`

2차 확장 탭 후보:

- `표지`

## 1. 스타일 탭

### 목적

문서 편집 중 현재 문단 또는 선택 영역에 기존 한글 스타일 이름을 빠르게 적용한다.

### 기능

- `bufs/templates/보고서 본문 서식.hwpx`에서 스타일 이름을 읽는다.
- 자주 쓰는 스타일은 즐겨찾기 버튼으로 보여준다.
- 전체 스타일 목록은 목록 또는 검색 가능한 드롭다운으로 보여준다.
- 선택한 스타일 이름을 현재 한글 문서의 현재 문단 또는 선택 영역에 적용한다.
- `스타일 세트 불러오기` 버튼을 제공한다.

### 스타일 적용 정책

- 스타일은 이름으로 적용한다.
- 1차 버전에서는 스타일의 실제 서식값을 직접 복사하지 않는다.
- 현재 문서에 같은 이름의 스타일이 있으면 적용한다.
- 현재 문서에 같은 이름의 스타일이 없으면 명확한 안내 메시지를 보여준다.

예상 메시지:

- `현재 문서에 해당 스타일이 없습니다.`
- `먼저 스타일 세트 불러오기를 실행해 주세요.`

### 스타일 세트 불러오기 정책

- 앱 시작 시 자동으로 실행하지 않는다.
- 사용자가 `스타일 세트 불러오기` 버튼을 직접 눌렀을 때만 실행한다.
- 대상은 현재 열려 있는 한글 문서다.
- `bufs/templates/보고서 본문 서식.hwpx`의 스타일 정의를 현재 문서로 가져온다.
- 같은 이름의 스타일이 이미 있으면 건너뛴다.
- 1차 버전에서는 기존 스타일을 덮어쓰지 않는다.
- 덮어쓰기/업데이트 기능은 나중에 고급 옵션으로 추가한다.

### 초기 즐겨찾기 스타일 후보

실제 구현 전 테스트에서 최종 목록을 조정하되, 1차 후보는 다음과 같다.

- `본문`
- `본문 1.`
- `본문 •`
- `본문 ◦`
- `표제목`
- `표내용 중간`
- `표내용 가운데`
- `표내용 왼쪽`
- `표내용 오른쪽`
- `표 아래 주석`
- `캡션`

## 2. 표 탭

### 목적

한글 표에서 반복적으로 수행하는 선, 셀 배경, 제목 셀, 문단 스타일 적용 작업을 버튼 한 번으로 처리한다.

### 선 종류 프리셋

1차 버전에서 지원할 선 종류는 네 가지다.

- `얇은 선`: 기본 선, 굵기 `0.12`
- `굵은 선`: 굵기 `0.3`
- `이중 선`: 굵기 `0.7`
- `점선`: 굵기 `0.12`

선 굵기 기본값:

| 선 종류 | 굵기 | 비고 |
| --- | ---: | --- |
| 얇은 선 | `0.12` | 기본값 |
| 굵은 선 | `0.3` | 제목 셀 상하선 등에 사용 |
| 이중 선 | `0.7` | 합계선, 구분선 등에 사용 |
| 점선 | `0.12` | 내부 가로 보조선 등에 사용 |

### 선 적용 위치 프리셋

1차 버전에서 지원할 적용 위치는 다음과 같다.

- `전체`
- `상하`
- `아래`
- `내부 가로`

### 초기 선 버튼

- `얇은 선 전체`
- `굵은 선 상하`
- `이중 선 아래`
- `점선 내부 가로`

### 기본 색상 팔레트

셀 배경색과 글자색은 같은 기본 팔레트를 사용하되, UI에서는 적용 대상을 분리한다.

- `셀 색깔`
- `글자 색깔`

기본 색상은 RGB 기준으로 다음 여섯 가지를 제공한다.

| 이름 | RGB | HEX | 기본 용도 |
| --- | --- | --- | --- |
| 노랑 | `255, 203, 5` | `#FFCB05` | 제목 셀, 강조 셀 |
| 진회색 | `85, 85, 85` | `#555555` | 보조 글자색, 진한 선 |
| 회색 | `150, 150, 150` | `#969696` | 보조선, 약한 글자색 |
| 연회색 | `204, 204, 204` | `#CCCCCC` | 표 셀 배경, 구분 배경 |
| 검정 | `0, 0, 0` | `#000000` | 기본 글자색 |
| 흰색 | `255, 255, 255` | `#FFFFFF` | 반전 글자색, 흰 배경 |

1차 버전에서는 팔레트 편집 UI를 만들지 않고, 위 기본값을 고정 팔레트로 제공한다.

### 복합 셀 프리셋

선 하나만 바꾸는 기능과 별도로, 셀의 여러 속성을 한 번에 적용하는 복합 프리셋을 둔다.

#### 제목 셀 프리셋

버튼 이름:

- `제목 셀`

사용 흐름:

1. 사용자가 한글 표에서 제목 셀로 만들 셀 범위를 선택한다.
2. `제목 셀` 버튼을 누른다.
3. 도구가 선택된 셀에 제목 셀 관련 설정을 한 번에 적용한다.

적용할 작업:

- 선택된 셀을 한글 표 속성의 `제목셀`로 설정한다.
  - 한글에서 셀을 선택하고 `P`를 눌렀을 때 셀 탭에 보이는 `제목셀` 옵션을 켜는 기능이다.
  - 이 설정은 색상/테두리/글자 스타일과 별개의 구조적 표 속성으로 취급한다.
- 선택된 셀 안의 문단에 제목 셀용 스타일을 적용한다.
- 선택된 셀에 제목 셀용 배경색을 적용한다.
- 선택된 셀에 제목 셀용 테두리 조합을 적용한다.
- 테두리는 다음 위치를 구분해서 설정할 수 있어야 한다.
  - 위
  - 아래
  - 왼쪽
  - 오른쪽
  - 내부 가로
  - 내부 세로

초기 설정 예시:

```json
{
  "cellPresets": {
    "header": {
      "label": "제목 셀",
      "setHangulHeaderCell": true,
      "paragraphStyle": "표내용 상단",
      "fillColor": "#FFCB05",
      "borders": {
        "top": "thick",
        "bottom": "thick",
        "left": "thin",
        "right": "thin",
        "insideHorizontal": "thin",
        "insideVertical": "thin"
      }
    }
  }
}
```

정확한 `paragraphStyle`과 색상 적용 대상은 `bufs/templates/보고서 본문 서식.hwpx`의 실제 스타일 이름, 기본 팔레트, 테스트 결과를 보고 조정한다.

### 이후 추가할 표 프리셋

`제목 셀` 프리셋이 안정적으로 동작한 뒤 다음 프리셋을 추가한다.

- `본문 셀`
- `합계 셀`
- `강조 셀`
- `빈 셀 정리`
- 사용자가 직접 표 프리셋을 편집하는 UI

## 3. 정리 탭

### 목적

예전 문서에서 자주 보이는 수동 줄바꿈, 스페이스바 정렬, 숫자 쉼표 문제를 정리한다.

### 1차 범위

- 선택 영역 기준으로만 실행한다.
- 전체 문서 정리는 기본 기능으로 제공하지 않는다.
- 전체 문서 정리는 나중에 별도 확인 절차가 있는 고급 기능으로 추가한다.

### 공백/줄바꿈 정리 버튼

- `선택 영역 공백 정리`
  - 줄 앞뒤 공백을 제거한다.
  - 안전한 경우 반복 공백을 한 칸으로 줄인다.
- `문장 중간 줄바꿈 이어붙이기`
  - 문장 중간에서 실수로 들어간 줄바꿈을 이어붙인다.
  - 필요하면 이어붙인 위치에 일반 공백 한 칸을 넣는다.
- `줄 앞 공백 제거`
  - 스페이스바로 가짜 정렬한 줄 앞 공백을 제거한다.

### 숫자/금액 정리 버튼

기존 `쉽다한글`에서 확인한 숫자 변환류 기능을 참고해 1차 정리 기능에 포함한다.

- `천원단위 쉼표 넣기`
  - 선택 영역 안의 숫자에 천 단위 쉼표를 넣는다.
  - 예: `1234567` → `1,234,567`
- `쉼표 빼기`
  - 선택 영역 안의 숫자 쉼표를 제거한다.
  - 예: `1,234,567` → `1234567`

### 숫자/금액 정리 안전 규칙

- 선택 영역 안에서만 동작한다.
- 숫자 내부의 쉼표만 대상으로 한다.
- 날짜, 전화번호, 문서번호, 코드값은 잘못 바뀔 수 있으므로 1차 구현에서 보수적으로 처리한다.
- 숫자 변환 전후에 한글의 일반 실행 취소로 되돌릴 수 있어야 한다.
- 표 안 숫자는 사용자가 셀 또는 범위를 명시적으로 선택했을 때만 처리한다.

### 정리 기능 안전 규칙

다음 항목은 가능하면 건드리지 않는다.

- 사용자가 명시적으로 선택하지 않은 표 내용
- 번호 목록
- 글머리표 목록
- 제목처럼 보이는 짧은 줄
- 날짜/서명/담당자/연락처 블록
- 마침표, 물음표, 느낌표 등 문장 종료 부호 뒤의 문단 구분

정리 기능은 공격적으로 고치기보다 보수적으로 동작해야 한다.

모든 정리 기능은 한글의 일반 실행 취소로 되돌릴 수 있어야 한다.

## 4. 표지 탭 또는 표지 확장 기능

### 목적

사용자가 최소한의 텍스트만 입력하면 `bufs/templates/표지.hwpx`의 디자인을 유지한 채 표지를 자동으로 삽입한다.

### 기본 템플릿

- `bufs/templates/표지.hwpx`

### 사용자 입력 방식

사용자는 다음 세 줄을 입력하는 간단한 방식으로 표지를 만들 수 있어야 한다.

```text
문서제목

날짜

부서명
```

UI에서는 세 개의 입력칸으로 받아도 된다.

- `문서제목`
- `날짜`
- `부서명`

### 자리표시자 치환

표지 템플릿 안의 자리표시자를 다음 값으로 바꾼다.

| 자리표시자 | 입력값 |
| --- | --- |
| `{{문서제목}}` | 문서 제목 |
| `{{날짜}}` | 날짜 |
| `{{부서명}}` | 부서명 |

### 대외비 여부

대외비 여부는 사용자가 선택한다.

- `대외비 표시`
- `대외비 표시 안 함`

처리 규칙:

- `대외비 표시`를 선택하면 표지 템플릿의 대외비 표시를 유지한다.
- `대외비 표시 안 함`을 선택하면 표지의 `<대 외 비>` 문구 또는 대외비 표시 영역을 제거한다.
- 대외비 표시 제거 방식은 단순 텍스트 삭제가 아니라, 표지 디자인이 깨지지 않는 방식으로 검증한다.

### 삽입 위치

기본 동작:

- 현재 문서 맨 앞에 표지를 삽입한다.
- 표지 뒤에 본문이 이어지도록 페이지 나누기를 유지한다.

나중에 추가할 옵션:

- 현재 커서 위치에 삽입
- 기존 첫 페이지를 표지로 교체

### 1차/2차 범위 판단

표지 샘플 파일이 이미 있으므로 표지 기능은 중요한 확장 기능이다.

다만 1차 핵심 범위는 `스타일`, `표`, `정리`로 유지한다.

표지 기능은 다음 중 하나로 다룬다.

1. 1차 구현이 예상보다 빨리 안정되면 `표지` 탭을 추가한다.
2. 아니면 2차 버전의 첫 번째 기능으로 구현한다.

## 1차 버전 비목표

- WebView 기반 UI로 화려하게 만들지 않는다.
- 앱 시작 시 스타일 세트를 자동으로 불러오지 않는다.
- 기존 스타일을 덮어쓰지 않는다.
- 전체 문서 정리를 기본 실행하지 않는다.
- 표지 삽입은 1차 핵심 범위에는 넣지 않는다.
  - 단, `bufs/templates/표지.hwpx` 샘플이 있으므로 2차 첫 번째 확장 기능으로 계획한다.
- 상용구/문서 조각 삽입은 1차 버전에 넣지 않는다.
- 팔레트 편집 UI는 1차 버전에 넣지 않는다.
- 이미지/로고 삽입 및 관리는 1차 버전에 넣지 않는다.
  - 단, `bufs/logos/` 아래에 우리대학 로고 4종을 보관하는 자산 구조는 미리 둔다.
- 검증된 COM 한계가 없는 한 무거운 의존성을 추가하지 않는다.

## 주요 기술 리스크

### 스타일 세트 불러오기

한 HWPX 문서의 스타일을 다른 문서로 안정적으로 가져오는 COM 경로는 확인이 필요하다.

후보 접근:

1. 한글의 스타일 가져오기/복사 액션을 COM으로 호출한다.
2. 스타일 라이브러리 문서를 임시로 열고, 스타일이 적용된 샘플 문단을 대상 문서로 복사한 뒤 삽입 내용을 정리한다.

1번이 안정적으로 동작하면 1번을 우선한다.

1번이 한글 버전/문서 상태에 따라 불안정하면 2번을 실용적 대안으로 둔다.

### 스타일 이름 적용

현재 문서에 해당 스타일 이름이 있어야 적용할 수 있다.

스타일이 없을 때 임의의 다른 스타일로 대체하면 안 된다.

예상 동작:

- `현재 문서에 해당 스타일이 없습니다` 안내
- `스타일 세트 불러오기` 실행 권장

### 표 테두리 자동화

한글 표 테두리 API는 셀 선택 상태와 한글 버전에 따라 다르게 동작할 수 있다.

구현 시 다음 경우를 반드시 테스트한다.

- 단일 셀 선택
- 여러 인접 셀 선택
- 한 행 선택
- 표 일부 영역 선택
- 표 안에 커서만 있고 명시적 셀 선택은 없는 상태

### 제목셀 속성 자동화

`제목 셀` 버튼은 보이는 서식뿐 아니라 한글 표 속성의 `제목셀` 플래그를 켜야 한다.

이 속성은 셀 배경색/테두리와 다른 구조적 속성이므로 별도로 검증한다.

### 정리 기능 자동화

정리 기능은 범위가 넓으면 문서 구조를 망가뜨릴 수 있다.

1차 버전은 선택 영역 기준으로만 동작하고, 규칙은 보수적으로 잡는다.

### 숫자 쉼표 자동화

천 단위 쉼표 넣기/빼기는 단순해 보이지만 날짜, 코드, 전화번호, 문서번호를 잘못 바꿀 수 있다.

1차 버전은 선택 영역 안의 명확한 숫자에만 적용한다.

## 구현 마일스톤

### 마일스톤 1: 한글 연결 검증

- 실행 중인 한글 인스턴스에 연결한다.
- 활성 문서가 있는지 감지한다.
- UI에 한글/문서 연결 상태를 표시한다.
- 현재 선택 영역 또는 문서 상태를 읽는 무해한 명령을 실행해 본다.

### 마일스톤 2: 스타일 목록 추출

- `bufs/templates/보고서 본문 서식.hwpx`에서 스타일 이름을 읽는다.
- 즐겨찾기 스타일과 전체 스타일 목록을 UI에 표시한다.
- 읽힌 스타일 목록이 실제 라이브러리 파일과 맞는지 확인한다.

### 마일스톤 3: 스타일 적용

- 선택한 스타일 이름을 현재 문단에 적용한다.
- 선택한 스타일 이름을 선택된 여러 문단에 적용한다.
- 스타일이 없을 때 명확한 안내 메시지를 보여준다.

### 마일스톤 4: 스타일 세트 불러오기

- `스타일 세트 불러오기` 기능을 구현한다.
- 같은 이름의 기존 스타일은 건너뛴다.
- 불러온 스타일이 이후 스타일 적용 버튼으로 적용되는지 확인한다.

### 마일스톤 5: 기본 표 선 프리셋

다음 버튼을 구현한다.

- `얇은 선 전체`
- `굵은 선 상하`
- `이중 선 아래`
- `점선 내부 가로`

여러 셀 선택 형태에서 결과를 테스트한다.

### 마일스톤 6: 제목 셀 프리셋

- `제목 셀` 버튼을 구현한다.
- 선택된 셀을 한글 표 속성의 `제목셀`로 설정한다.
- 선택된 셀에 스타일, 배경색, 테두리 프리셋을 적용한다.
- 단일 셀, 한 행, 여러 셀 선택에서 동작을 확인한다.

### 마일스톤 7: 공백/줄바꿈 정리 기능

- 선택 영역 기준 정리 기능을 구현한다.
- 정리 규칙은 보수적으로 둔다.
- 각 동작이 한글 실행 취소로 되돌아가는지 확인한다.

### 마일스톤 8: 숫자 쉼표 정리 기능

- `천원단위 쉼표 넣기`를 구현한다.
- `쉼표 빼기`를 구현한다.
- 선택 영역 안의 일반 숫자에서 동작을 확인한다.
- 날짜, 전화번호, 코드값을 잘못 바꾸지 않는지 테스트한다.

### 마일스톤 9: 표지 자동화 확장

2차 첫 번째 확장 기능으로 계획한다.

- `bufs/templates/표지.hwpx`를 표지 템플릿으로 사용한다.
- `문서제목`, `날짜`, `부서명`을 입력받는다.
- `{{문서제목}}`, `{{날짜}}`, `{{부서명}}` 자리표시자를 치환한다.
- 대외비 여부를 선택받는다.
- 대외비 표시 안 함을 선택했을 때 표지 디자인이 깨지지 않는 방식으로 `<대 외 비>` 표시를 제거한다.
- 표지를 현재 문서 맨 앞에 삽입한다.

## 완료 기준

- 사용자가 한글을 열고 텍스트를 선택한 뒤 스타일 버튼을 눌러 이름 기반 스타일을 적용할 수 있다.
- 사용자가 기존 문서에 스타일 세트를 불러올 수 있고, 같은 이름의 스타일은 덮어쓰지 않는다.
- 사용자가 표 셀을 선택해 네 가지 기본 선 프리셋을 적용할 수 있다.
- 사용자가 제목 셀 범위를 선택해 `제목 셀` 복합 프리셋을 적용할 수 있다.
- `제목 셀` 프리셋은 한글의 구조적 `제목셀` 속성까지 설정한다.
- 사용자가 선택 영역에 공백/줄바꿈 정리 기능을 실행할 수 있다.
- 사용자가 선택 영역에 `천원단위 쉼표 넣기`와 `쉼표 빼기`를 실행할 수 있다.
- 스타일이 없거나 한글 활성 문서가 없을 때 명확한 안내 메시지를 보여준다.
- 1차 패키징 결과가 WebView/Pillow/NumPy 기반 참고 앱보다 가볍게 유지된다.

## 2차 확장 완료 기준: 표지

- 사용자가 `문서제목`, `날짜`, `부서명`을 입력해 `bufs/templates/표지.hwpx` 기반 표지를 만들 수 있다.
- 대외비 표시 여부를 선택할 수 있다.
- 대외비 표시 안 함을 선택해도 표지 레이아웃이 깨지지 않는다.
- 생성된 표지는 현재 문서 맨 앞에 삽입된다.
